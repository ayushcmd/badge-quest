# Sources

Information last checked: 8 November 2026.

## Primary

- GitHub Docs, [Manage visibility settings for private contributions and achievements](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements): where to show or hide achievements, hide a single badge, and show private contributions.
- GitHub Docs, [Creating a commit with multiple authors](https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors): the `Co-authored-by` trailer.
- GitHub Docs, [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site): publishing from a branch and the `/docs` folder.
- GitHub Docs, [GitHub Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service): one free account per person.
- GitHub Docs, [About Discussions](https://docs.github.com/en/discussions/collaborating-with-your-community-using-discussions/about-discussions).
- GitHub Sponsors, [Explore sponsorable people and projects](https://github.com/sponsors/explore).
- GitHub Support, [support.github.com](https://support.github.com/).

## Community references

These are not official, so treat them as hints and re-check anything that matters.

- [Schweinepriester/github-profile-achievements](https://github.com/Schweinepriester/github-profile-achievements): community list of all achievements, widely cited in GitHub's own Community forum.
- [gomzyakov/achievements](https://github.com/gomzyakov/achievements): badge list with tier thresholds.
- [drknzz/GitHub-Achievements](https://github.com/drknzz/GitHub-Achievements): linked from the guide this repo started from.
- Replies from GitHub staff in the GitHub Community discussions, stating that achievements are no longer awarded in the Community forum itself.

## Starting material

The first draft of the criteria and the troubleshooting checklist came from a GitHub Achievements guide supplied by the repository owner. Where it differed from GitHub Docs, such as the names of the visibility switches, the GitHub Docs wording was used.

## Known uncertainty

- Heart On Your Sleeve and Open Sourcerer have no official criteria.
- GitHub can change tiers, rules and settings labels without notice.
