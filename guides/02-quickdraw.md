# Quickdraw

## The rule

Close an issue or a pull request within 5 minutes of opening it.

## Tiers

None. Quickdraw is a one-time badge. Once you have it, it will not appear again.

## Difficulty

Very easy.

## Steps

1. Create a public practice repository, for example `badge-practice`, and tick Add a README file.
2. Open the Issues tab and click New issue.
3. Give it a title such as `Quickdraw test` and click Submit new issue.
4. Start a 5 minute timer the moment you submit.
5. Click Close issue well before the timer ends.
6. Wait up to 24 hours and check your profile sidebar.

A pull request works too, but an issue is the simplest route.

## Common mistakes

- Waiting more than 5 minutes. Opening and closing in the same minute is perfectly fine.
- Working only in a fork. Do this in a repository you own, or in the original project.
- Expecting more badges from doing it again. It is one-time.

## Fair play

Close your own practice issue. Do not open and instantly close issues in other people's projects, because that sends notifications to maintainers for no reason.
