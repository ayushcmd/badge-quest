# Retired Badges, Unreleased Badges and Profile Highlights

## Retired badges

These were tied to a specific event and can no longer be earned. If you see them on a profile, that person contributed at the time.

| Badge | What it was for |
| --- | --- |
| Arctic Code Vault Contributor | Code included in the 2020 GitHub Archive Program snapshot |
| Mars 2020 Contributor | Code contributed to repositories used by the Mars 2020 helicopter mission. It was previously named Mars 2020 Helicopter Contributor |

## Listed but unreleased

Heart On Your Sleeve and Open Sourcerer appear in lists of badge assets, but GitHub has not published criteria for them. Some websites guess at the rules. Treat those guesses as unverified, and do not expect these badges to unlock.

## Profile highlights are not achievements

Other items in the sidebar show status or program membership:

| Highlight | What it shows |
| --- | --- |
| GitHub Pro | An active Pro subscription |
| Developer Program Member | Membership in GitHub's developer program |
| Security Bug Bounty Hunter | Credit for reporting vulnerabilities |
| GitHub Campus Expert | Recognition for student leaders |
| Security Advisory Credit | Contributions to the GitHub Advisory Database |

Most achievements stay once earned. Highlights tied to account status, such as GitHub Pro, disappear when the subscription or membership ends.
