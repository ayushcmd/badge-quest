# GitHub Achievements: Overview

Achievements are small badges that appear in the sidebar of your GitHub profile. Each one marks a specific action, such as getting a pull request merged, having an answer accepted in Discussions, or sponsoring a developer. Hover over a badge on a profile to see how it was earned.

GitHub introduced them in 2022, and they quickly turned into a friendly challenge: earn your first Pull Shark, collect a Galaxy Brain, and so on.

## Three kinds of badges

1. Earnable now: Starstruck, Quickdraw, Pair Extraordinaire, Pull Shark, Galaxy Brain, YOLO and Public Sponsor.
2. Retired: tied to a one-off event in the past and no longer awarded, such as Arctic Code Vault Contributor and Mars 2020 Contributor.
3. Listed but unreleased: Heart On Your Sleeve and Open Sourcerer show up in badge asset lists, but there are no published criteria.

Profile highlights such as GitHub Pro or Developer Program Member also sit in the sidebar. They show your status or program membership. They are not achievements. See [10-retired-and-unreleased.md](10-retired-and-unreleased.md).

## Tiers

Four badges have tiers. The first tier is called Default, and then come Bronze, Silver and Gold.

| Badge | Default | Bronze | Silver | Gold | What is counted |
| --- | --- | --- | --- | --- | --- |
| Starstruck | 16 | 128 | 512 | 4096 | Stars on a single repository |
| Pair Extraordinaire | 1 | 10 | 24 | 48 | Merged pull requests with co-authored commits |
| Pull Shark | 2 | 16 | 128 | 1024 | Merged pull requests you opened |
| Galaxy Brain | 2 | 8 | 16 | 32 | Replies accepted as answers in Discussions |

Quickdraw, YOLO and Public Sponsor are one-time badges with no tiers.

## Rules that apply to every badge

- Public work counts by default. Private work only shows up if you turn on the private contributions option, and it appears as anonymized counts. See [01-profile-and-visibility.md](01-profile-and-visibility.md).
- Work that exists only in a fork does not count. To make it count, open a pull request that gets merged into the parent repository.
- Commits must use an email address that is added and verified on your account.
- Work on a non-default branch does not count until it is merged into the default branch.
- A new badge can take up to 24 hours to appear.

If a badge is missing, go to [09-troubleshooting.md](09-troubleshooting.md).

## Skin tone

Some badges are drawn with the skin tone you picked in your Appearance settings. This changes how they look, not how you earn them.

## How to use this repo

Read the guide for the badge you want, or open the learning site in `docs/` and play through the levels in order. Level 1 covers settings and email checks that save you from most "why is my badge missing" problems later.
